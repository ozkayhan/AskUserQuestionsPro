<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> loopback HTTP/SSE | Browser-controlled exact selectors and lifecycle observations cross the local API boundary. |
| bridge -> private round store | Exact deletion and lifecycle filtering mutate or read private local records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-01 | Tampering | POST /rounds/:roundId/delete | medium | mitigate | Require an exact syntactically valid roundId, re-check expiry and recoverable lifecycle in Bridge.deleteRecoverable(), and reject terminal/unrelated records before RoundStore.remove(). |
| T-19-02 | Information disclosure | GET /rounds and delete responses | high | mitigate | Use Record.metadata only, return no deletion payload, and assert absence of answers, capabilities, paths, question text, and diagnostics in bridge/server/browser-boundary tests. |
| T-19-03 | Denial of service | hydrated deletion cleanup | medium | mitigate | Clear matching _pending/_deliveries/_completed ownership and all associated timers, reject waiters deterministically, and broadcast a null snapshot without affecting unrelated rounds. |
</threat_model>
