<objective>
Implement the dependent browser lifecycle and recovery state machine: permanently retire submitted tabs, close only after acknowledgement, render explicit discovery states, and expose the approved exact-round recovery actions with accessible human-first surfaces.

Purpose: The server plan supplies authoritative records and deletion; this plan connects those contracts to App state and existing React/CSS seams so a stale tab cannot duplicate a later round and a recoverable interruption cannot be mistaken for normal delivery.
Output: Guarded SSE hook, App callbacks and state flow, contract-compliant views/CSS, focused source and accessibility tests, and a supported manual localhost/host verification path.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| EventSource -> browser App | Untrusted/replayed lifecycle snapshots and reconnect callbacks can affect mounted round state. |
| browser recovery controls -> loopback HTTP | User-controlled exact selectors invoke resume/delete operations. |
| browser UI -> assistive technology | Rendered labels and metadata can disclose payloads if redaction is bypassed. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-04 | Tampering | stale EventSource callbacks | high | mitigate | Gate onmessage, onerror, reconnect timers, and snapshots with permanent retirement plus generation/round identity checks; test old callbacks after close denial. |
| T-19-05 | Tampering | recovery action callbacks | medium | mitigate | Store exact selected roundId/requestId, defer Continue, confirmation-gate delete, keep chooser state on failures, and make Start a new round non-destructive. |
| T-19-06 | Information disclosure | recovery views and labels | high | mitigate | Render only redacted server metadata and approved human copy; assert absence of question/answer/capability/path/diagnostic content in accessibility and cross-file tests. |
| T-19-07 | Denial of service | reconnect loop and repeated submit | medium | mitigate | Retire before delivery, lock inflight submit, clear timers, cap existing reconnect backoff, and prevent retired tabs from creating new generations. |
</threat_model>
