# Plan 05-01: CLI, installer, and host-operation hardening

## Goal

Give users actionable diagnostics and make host-scoped install/uninstall behavior
safe, idempotent, and testable without touching a real home directory.

## Tasks

1. Add regression tests for explicit target boundaries, host executable overrides,
   doctor/install behavior when a host binary is missing, and installer/reinstaller
   argument validation and local-source execution.
2. Audit CLI subprocess calls for `error`/non-zero handling and ensure `doctor`
   remains read-only and reports a concrete next action for missing host binaries,
   stale MCP paths, missing skills, and malformed settings.
3. Harden shell-script source validation and cleanup boundaries where tests expose
   stale-file, unsafe-path, or shared-runtime regressions. Keep cleanup limited to
   known project-owned paths and preserve the other host’s runtime.
4. Add/update documentation for the supported installer entry points and the
   `doctor` decision tree, including the exact environment overrides used by CI and
   local diagnostics.

## Verification

- `node --test test/cli.test.js test/host-platforms.test.js test/shell-lifecycle.test.js`
- Shellcheck all repository installer scripts.
- `git diff --check` and targeted lint/format checks.
