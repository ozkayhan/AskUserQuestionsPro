# Plan 05-02: Package boundary, metadata, and release gates

## Goal

Make the published package reproducible and ensure local and CI quality gates
exercise the same application surface.

## Tasks

1. Add failing package-boundary tests that compare the npm dry-run manifest with an
   explicit allowlist and assert package/lockfile version and Node engine parity.
2. Exclude `.codex/` and other non-source workspace artifacts consistently from
   ESLint and Prettier; add a regression assertion so future local bundles cannot
   break release gates.
3. Synchronize package metadata with the lockfile and document what is intentionally
   shipped versus kept as repository-only documentation/tests/tooling.
4. Run the complete release gate locally: clean install, tests, lint, format check,
   shellcheck, production audit, package dry-run, and diff checks. Fix only
   application/release issues surfaced by those gates.

## Verification

- `npm ci`
- `npm test`
- `npm run lint`
- `npm run format:check`
- `npm audit --audit-level=high --omit=dev`
- `npm pack --dry-run --json`
- shellcheck all `*.sh` files outside `node_modules`.
