cancellation or round ownership.

3. Add `/resume`, `resumeBridge()`, `cancelBridge()`, and the MCP `resume` tool.
4. Make MCP `notifications/cancelled` issue explicit `/cancel` before aborting
   the owner stream.
5. Add a real MCP process boundary test and run the Codex CLI smoke reproduction.
