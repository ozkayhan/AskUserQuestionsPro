## Cross-phase integration

The integration checker verified the following connected paths:

- host ask → lifecycle attribution → durable registration → SSE/browser projection;
- draft autosave → revision-guarded durable store → reconciliation;
- browser answer → immutable result → host response;
- result acknowledgement → delivery state → optional close/fallback;
- host detach/restart → exact adapter resume;
- settings schema → persistence/CAS → server, CLI, runtime, and browser consumers;
- evidence ledger → compatibility matrix → capability cards → fail-closed release gates.

The checker initially found that `web/live.js` called `POST /resume/<roundId>` while the server accepted `POST /resume` with a JSON selector. Commit `9244f25` aligned the browser call with the server contract and added a regression test. The rerun scored 9.5/10 with zero critical blockers.
