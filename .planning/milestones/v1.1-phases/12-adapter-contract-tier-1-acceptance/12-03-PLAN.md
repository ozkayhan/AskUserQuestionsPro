| Installer → user host configuration | Scripts mutate files and registrations under host-specific home/config paths. |
| Doctor/evidence output → maintainer | Diagnostics may expose paths, secrets, capabilities, or payloads if not redacted. |

## STRIDE Threat Register
| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-12-05 | Tampering | install/uninstall target scope | high | mitigate | Isolate HOME/CODEX_HOME tests and assert only selected host artifacts change; preserve unrelated settings. |
| T-12-06 | Information disclosure | doctor and evidence output | medium | mitigate | Assert allowlisted redacted output and synthetic payloads only; never print credentials or answer content. |
| T-12-07 | Repudiation | support evidence state | medium | mitigate | Record command, host version, date, scenario, result, and limitation; label unavailable authenticated runs explicitly. |
| T-12-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package-manager task; only existing shell/Node surfaces are exercised. |
</threat_model>
