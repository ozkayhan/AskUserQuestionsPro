<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → HTTP/SSE bridge | Browser reads active-round snapshots and submits state-changing answer/cancel requests. |
| bridge → stderr diagnostics | Operational metadata leaves the process and can be copied into support artifacts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-04 | Information disclosure | Lifecycle logger | high | mitigate | Use an allowlisted DTO and redaction tests that prove question/answer fields never serialize. |
| T-08-05 | Tampering | /answer and /cancel | high | mitigate | Require matching id and opaque capability; return conflicts without state mutation. |
| T-08-06 | Spoofing | Lifecycle boundary labels | medium | mitigate | Normalize values in the shared lifecycle recorder and set owners only at known host/transport call sites. |
| T-08-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installation is permitted in this plan; retain zero runtime dependencies. |
</threat_model>
