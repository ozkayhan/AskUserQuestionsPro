## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Local browser/host to HTTP API | Untrusted request bodies and selectors request discovery, recovery, result, or acknowledgement operations. |
| HTTP API to durable Bridge | Route data must be converted into exact selection and ownership checks without leakage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|----------|----------|-----------|----------|-------------|-----------------|
| T-09-11 | Information disclosure | `GET /rounds` and error paths | high | mitigate | Return only redacted metadata and opaque typed errors; assert omissions in real HTTP tests. |
| T-09-12 | Spoofing | result/ack selectors | high | mitigate | Require exact durable ID plus matching ownership material; reject mismatched request/capability values. |
| T-09-13 | Tampering | acknowledgement and resume handlers | high | mitigate | Delegate to persisted immutable/idempotent Bridge transitions; never mutate based only on route order. |
| T-09-14 | Denial of service | malformed selectors/corrupt records | medium | mitigate | Validate at the HTTP boundary and map per-record recovery outcomes to bounded typed responses. |
| T-09-15 | Repudiation | result delivery endpoint | medium | mitigate | Return persisted revision and acknowledgement facts from the record rather than transient response state. |
</threat_model>
