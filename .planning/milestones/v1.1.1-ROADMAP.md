**Status:** Release prepared; publication and tag are delegated to the authenticated Changesets workflow.
**Closed:** 2026-07-18 (override closeout; see audit and deferred items)

**Total Plans:** 15 planned, 14 executed to completion, 1 release-decision plan superseded by the prepared changeset flow

## Overview

This milestone turned the shipped v1.1 implementation into a reproducible, quality-gated, privacy-preserving release candidate. It resolved static quality failures, refreshed browser/UAT evidence, reran security and installer checks, synchronized maintained documentation, and assembled a clean-checkout release gate. The repository now carries a patch changeset for `askuserquestionspro`; the GitHub Actions Changesets workflow remains the authoritative path for changing package metadata to 1.1.1, creating the tag, and publishing to npm.

## Milestone Summary

### Key decisions

- Keep the patch release on the repository’s standard Changesets automation path; do not manually tag or publish an unauthenticated 1.1.0 checkout as v1.1.1.
- Preserve external Claude/Codex, Windows/Linux, and assistive-technology limitations as explicit handoffs.
- Run the full suite serially and browser CLI evidence as a dedicated gate to avoid transient scheduler and daemon-socket races.
- Preserve user-owned `.planning/config.json`, `.planning/ui-reviews/.gitignore`, and generated `.playwright-cli/` artifacts.

### Issues resolved

- 17 ESLint errors and broad formatting drift were resolved with maintained, reviewable scope.
- Deterministic clean-checkout quality, package, security, documentation, shell, and installer evidence was assembled.
- Settings/recovery/delivery evidence and redaction boundaries were refreshed and cross-linked.

### Issues deferred

- Authenticated Claude/Codex acceptance, native Windows/Linux validation, and exhaustive browser/AT scenarios require their real environments.
- npm publication and the `v1.1.1` tag occur after merge through `.github/workflows/release.yml` and its `NPM_TOKEN` secret.
- A pre-existing trailing whitespace finding in historical Phase 17 evidence remains untouched.

See `.planning/v1.1.1-MILESTONE-AUDIT.md` and `docs/evidence/v1.1.1-release-handoff.md` for the complete evidence map.
