## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-10-01 | Tampering | schema import/migration | high | mitigate | Strict version/enumeration/bounds validation; future versions are rejected and current files are preserved. |
| T-10-02 | Elevation of privilege | settings envelope | critical | mitigate | Exclude executable commands, adapter command strings, secrets, and loopback/security controls from accepted fields and projections. |
| T-10-03 | Availability | settings persistence | medium | mitigate | Atomic temp-write/rename, backup before migration, and typed failure results preserve the last valid file. |
| T-10-SC | Tampering | npm/pip/cargo installs | high | accept | No package installation is planned; retain zero runtime dependencies. |
</threat_model>
