## Status and evidence policy

- `PASS` means the cited local command or retained artifact directly proves the row.
- `PARTIAL` means the local contract/evidence is valid but an external lane remains open.
- `UNAVAILABLE` means the required environment or independent runtime evidence was not available; it is not a failure count and never promotes a capability claim.
- All historical reports remain byte-for-byte archive inputs. Archived counts and tool gaps are labelled snapshots or superseded where Phase 14/15 provides newer evidence.
- This maintained artifact contains only paths, statuses, counts, owners, environments, and next gates. It excludes sensitive payloads and raw host transcripts.
