- Bridge.markDeliveryUncertain(roundId) keeps immutable answers available in delivery-uncertain.

- RoundStore.recoverable() is startup hydration policy for records without immutable answers.

From server/server.js:
- GET /rounds already delegates to bridge.listRecoverable().
- POST /rounds/:roundId/ack validates the opaque capability and calls bridge.confirmDelivery().
- POST /cancel is for numeric active-round ownership and is not sufficient to remove an uncertain durable record; the new exact-round delete route must be separate.
- sendIndex() injects both window.__ASKUSER_SETTINGS__ and window.__ASKUSER_SETTINGS_V2__.

From web/live.js:
- useLiveQuestions() owns EventSource('/events'), closed, generation, reconnect timers, and the round snapshot state.
- acknowledgeDelivery(id, capability) returns { ...body, state: 'delivered', acknowledged: true } or throws RecoveryError for uncertainty.
- attemptClose(close) returns { closed: true, denied: false } or { closed: false, denied: true }.
- deliveryTransition(state, event) maps pending acknowledgement to delivered and timeout/network failure to delivery-uncertain.
- Browser/global and CommonJS dual-use is required; pure lifecycle helpers belong in the existing export/global seams.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser -> loopback bridge | Browser-controlled selectors and lifecycle callbacks cross the localhost HTTP/SSE boundary. |
| bridge -> local round store | Recovery deletion and lifecycle filtering mutate private local round records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-01 | Tampering | exact-round delete/ack routes | medium | mitigate | Keep destructive recovery scoped to an exact roundId, reject non-recoverable/expired records, preserve existing ownership checks for answer and acknowledgement operations, and return no payload. |
| T-19-02 | Information disclosure | /rounds metadata and recovery views | high | mitigate | Continue using Record.metadata, omit answers/capabilities/paths/diagnostics, and assert redaction in bridge, server, and browser integration tests. |
| T-19-03 | Denial of service | EventSource reconnect and retired tabs | low | mitigate | Invalidate generations, clear timers, close retired EventSources, and keep the existing bounded reconnect backoff. |
</threat_model>
