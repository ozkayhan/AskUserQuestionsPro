|---|---|
| Local browser/host → loopback HTTP | Untrusted local requests can attempt stale or cross-round mutations. |

| T-17-02 | Information Disclosure | lifecycle/settings/evidence projections | high | mitigate | Use existing allowlist projections and nested unknown-value regression fixtures. |
| T-17-03 | Tampering/Denial of Service | installer and host config | high | mitigate | Isolated-root tests require exact scoped mutation, preservation, conflict handling, and idempotent removal. |
