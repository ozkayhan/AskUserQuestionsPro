# Code of Conduct

## Our standard

We are committed to making participation in AskUserQuestionsPro welcoming,
respectful, and harassment-free for everyone, regardless of age, disability,
ethnicity, gender identity or expression, level of experience, nationality,
personal appearance, race, religion, or sexual identity and orientation.

Expected behavior includes:

- listening to different perspectives and giving feedback about ideas rather
  than people;
- using inclusive, professional language;
- accepting correction and improving the discussion; and
- respecting privacy and never publishing another person’s private
  information, credentials, question content, or host logs.

Unacceptable behavior includes harassment, discrimination, threats, personal
attacks, sexualized language or imagery, doxxing, deliberate disruption, and
publishing sensitive information without consent.

## Enforcement

Project maintainers may edit, remove, or reject comments, commits, issues,
pull requests, and other contributions that violate this code. They may also
temporarily or permanently restrict participation when necessary to protect
the community.

To report a conduct concern, contact the repository maintainers privately
through GitHub rather than posting details publicly. For an immediate security
risk, follow [SECURITY.md](SECURITY.md). Reports will be handled as
confidentially as the available GitHub tooling permits.

This code of conduct is adapted from the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.
