# Release evidence handoff

This page is a maintained, reproducible evidence boundary rather than a ship
decision. Local checks demonstrate the repository contract; they do not imply
authenticated host or native-OS support.

## Local evidence to record

Run these commands from a clean checkout and attach their current output to a
release record:

```bash
npm ci
npm test
npm run lint
npm run format:check
npm audit --audit-level=high --omit=dev
npm pack --dry-run --json
bash -n install.sh uninstall.sh reinstall.sh
```

The local gate covers unit/integration behavior, formatting, package
boundaries, dependency policy, and shell syntax. Browser, accessibility,
installer, and cross-platform checks must be recorded separately when they
are required by the release scope.

## External evidence

The following rows remain unavailable until an owner runs them in the named
environment. Missing authentication or host binaries are evidence gaps, not
passes.

| Lane                      | Required evidence                                                                                    |
| ------------------------- | ---------------------------------------------------------------------------------------------------- |
| Authenticated Claude Code | Version-pinned hook round, idle/reconnect, cancellation, delivery, and native fallback               |
| Authenticated Codex       | Version-pinned MCP round, host disconnect, exact resume, cancellation, delivery, and native fallback |
| Native Windows            | Installer, host registration, recovery, browser, and uninstall checks                                |
| Native Linux              | Installer, host registration, recovery, browser, and uninstall checks                                |

Do not include question text, answers, credentials, or private host logs in an
evidence record. Use opaque round IDs and redacted lifecycle events.
